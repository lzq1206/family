# 李氏家谱网页版

这是把 `data/paper/李氏家族（全部内容）.pdf` 整理成的静态网页首版，适合直接部署到 GitHub Pages。

## 内容
- 家族概览
- 谱前补记与说明（旧谱序缺失、PDF 第 8-9 页、李姓溯源、家训等）
- 人口变化与教育统计
- 世系索引（支持“世系方式 / 树状图”双标签切换）
- 家族记忆与家训摘要
- 人物详情中的“记事”字段

## 说明
- 当前页面优先“可浏览、可检索、可继续校对”。
- 早期世系部分存在 OCR 识别误差，后续可继续人工逐页校对。
- 为避免仓库过大，未直接把原始 PDF 放入 GitHub 仓库。

## 本地查看
直接打开 `index.html` 即可。
